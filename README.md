# Laboration 2 | Programmering i TypeScript 
I denna laboration har vi fått öva på objektorienterad TypeScript. Applikationen låter användaren skapa, slutföra och 
ta bort uppgifter samt organisera dem efter prioritet. Varje uppgift tilldelas en prioritet och ett förfallodatum. 
Uppgifterna sorteras automatiskt efter prioritet, medan slutförda uppgifter placeras längst ner i listan. 

Applikationen använder ett TypeScript-interface och en klass för att hantera uppgifternas logik och validering. Uppgifterna lagras i webbläsarens 
LocalStorage så att de finns kvar även efter att sidan laddats om.
